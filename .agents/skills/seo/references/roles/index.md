# Specialist prompts

Use only the specialists relevant to the scope. Give the prompt the target, allowed sources, and observed limitations. Apply it inline when delegation is unavailable. Each specialist inspects assigned evidence read-only and reports independent findings. The lead owns scope, conflict resolution, and the final report.
