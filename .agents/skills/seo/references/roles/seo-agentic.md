# Agentic browsing specialist

Apply the [agentic browsing workflow](../guides/seo-agentic.md) to the assigned scope. Trace a representative user task with the host's passive browser capabilities. Check visible semantics, accessibility, machine-readable affordances and confirmation boundaries. Distinguish observed interface evidence from attempted or completed actions.

Return the checks attempted, URLs or files inspected, findings with severity, recommended fixes, and confidence and coverage limits. Mark unavailable checks and name the needed evidence. Work read-only and send findings to the lead.
