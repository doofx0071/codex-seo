# Content and on-page quality gates

Check that the page's title, heading, description, actual content, and internal link labels describe the same purpose. Title and description lengths are editorial checks. Search snippets may vary by query and the search surface can rewrite them. Use specificity and distinctiveness before hard counts.

Inspect useful content rather than assuming long copy is stronger. First-hand detail, trustworthy citations and relevant internal links can improve utility. Compare independent samples before calling a template problem sitewide. For pages that serve similar intents, distinguish repeated navigation from repeated primary content.
