# Search and analytics evidence

| Evidence | Keep with each result |
|---|---|
| Search Console or Bing | Property, dates, search type, country, device, filters, dimensions and available depth |
| Analytics | Project or property, attribution, time zone, event definitions, filters, channel and landing-page scope |
| Third-party SERP or keyword data | Provider, date, query, observed versus estimated value, device, locale and depth |
| URL inspection | Requested URL, result source, retrieval date, and whether it describes a live test or indexed state |

Check sampling, aggregation and omitted queries before comparing. Use periods of similar duration and conditions. Label partial evidence, changes in instrumentation, known missing events, and data gaps. Public search results may provide observations for specific queries and do not establish property-wide trends.
