# FLOW framework

FLOW means Find, Leverage, Optimize, and Win.

1. Find. Identify who needs the answer, what they search for, and where current pages do or do not serve that need.
2. Leverage. Map comparable pages, coverage gaps, first-hand assets, and useful internal links. Choose a few gaps for which credible evidence is available.
3. Optimize. Draft a better page promise, structure and evidence. For existing pages, address search intent and accessibility without removing useful context.
4. Win. Define a desired outcome and the metric or observable condition that tests it. Prioritize the changes and establish a checkpoint with a comparable baseline.

Adapted from [FLOW by Daniel Agrici](https://github.com/AgriciDaniel/flow), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). This summary selects and rewrites the stages for use with host evidence.
