# Search experience criteria

Classify the required task and the type of pages shown in observable results. Ask what a first-time visitor, returning reader or buyer needs next. Use the personas relevant to the request.

| Dimension | What to inspect |
|---|---|
| Intent fit | Query, page promise, visible main content |
| Comprehension | Labels, order, language, comparison or decision support |
| Evidence | Clarity, credibility, originality and recency |
| Friction | Navigation, pop-ups, device constraints, barriers |
| Completion | Discoverable next steps, expected success state |

Give a rationale and tested viewpoint for each judgment. Use the dimensions as a prioritization rubric. Quantitative UX or conversion claims require actual measurements.
