# SERP overlap

Compare organic result URLs for queries under the same available locale, device, date, and retrieval conditions. Document depth and how you normalized URLs. For two result sets, use shared URLs divided by total distinct URLs as a simple overlap measure. Inspect page type and intent manually alongside the number.

Strong shared coverage suggests queries may belong on one page. Weak coverage or different result types may justify a separate page. Search snippets, blended features and limited result access can bias the sample. Label unsupported clusters as semantic hypotheses. Compare with the site's existing content and user tasks before assigning new pages.
