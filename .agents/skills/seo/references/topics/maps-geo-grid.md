# Map geo-grid evidence

For a user-supplied grid, record the search term, scan date, coverage, grid geometry, profile matched, result cutoff, and how the provider handles missing positions. Compare like-for-like scans only. A visible grid share can use cells where the business meets a documented rank threshold divided by all valid scanned cells. Show both counts and how missing cells were handled.

One listing lookup cannot establish grid coverage or citywide visibility. Keep omitted locations or inaccessible exports explicitly unavailable.
