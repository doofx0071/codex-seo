# Structured data

Capture JSON-LD from raw source or a rendered DOM when accessible. Note which one you inspected and consider microdata or RDFa when relevant. Parse the actual markup when the host permits. Check @context, @type, @id, nested entities, broken references, conflicts, expected values, and consistency with visible content.

Distinguish JSON syntax, Schema.org vocabulary conformance, and eligibility for a specific search feature. Check the [type and eligibility reference](../topics/schema-types.md) and current primary documentation. Report validator results only if actually available. Describe absent markup only when the inspected source was complete enough to support that claim.

If asked for markup, provide a clearly labeled draft using facts the user supplied or the page confirms. Never invent reviews, ratings, prices, offers, authorship, or contact information. List checks needed before deployment.
