# SEO drift review

Compare a baseline and current snapshot or supplied reports using the same URL scope, source, capture mode and field definitions. Track status and redirects, index directives, canonical changes, key headings, rendered changes and public sitemap shifts. Compare like-for-like search and performance metrics only when their scope and conditions match.

Use [comparison rules](../topics/comparison-rules.md) to distinguish changed, removed, unreachable, and unknown values. Tie critical changes to observed pages with both dates. Without a baseline, document current evidence and the fields to recapture. A comparison does not schedule monitoring.
