# DataForSEO exports

Interpret supplied SERP, keyword, backlink, marketplace, or technical reports. Record provider, endpoint or export name if stated, query, target, reported time, search environment, location, device, depth and units. Distinguish estimated metrics from source observations, and take care comparing differently scoped extracts.

Use [search and analytics evidence](../topics/search-analytics.md) to label data gaps. No paid provider endpoints are in scope. When no report is supplied, use observable public evidence for the parts it can support and label provider metrics unavailable.
