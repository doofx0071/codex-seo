# PostHog analytics evidence

Review user-supplied web analytics, events or funnel output. Record project, time zone, filters, event names, attribution method and conversion definition. Separate event counts, users, and sessions. Classify organic sources only when source, referrer, or campaign logic supports it.

Use [search and analytics evidence](../topics/search-analytics.md) to compare periods or landing-page cohorts, and state selection or instrumentation limits. Missing or unconfigured events are not zero conversions. Make recommendations about measurement and content without changing events or project settings.
