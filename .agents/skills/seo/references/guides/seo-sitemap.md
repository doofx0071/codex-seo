# Sitemap analysis and generation

Use public robots.txt declarations and user-supplied URLs to find candidate sitemaps. Read the XML if the host exposes it. Determine whether a file is a sitemap or an index, then list which child files and URLs you were able to sample. Check namespace, URL syntax, duplicate locations, expected scope, and whether sampled entries are successful, canonical, indexable destinations.

Separate URLs advertised by a sitemap from URLs retrieved and from URLs indexed. Never claim full coverage from part of a sitemap. Treat lastmod as meaningful only when supported by substantial changes. For large inventories or image, video, news, or alternate-language extensions, use the [sitemap reference](../topics/sitemap-validation.md).

For a requested draft sitemap, use known intended canonical URLs. Give the draft or an example and mark any missing inventory. Do not submit it or write to the site.
