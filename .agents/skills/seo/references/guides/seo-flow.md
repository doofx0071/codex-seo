# FLOW strategy

Use [the FLOW framework summary](../topics/flow-framework.md) to move from evidence to a focused execution plan. Choose the stage that matches the request. Find starts with audience and intent. Leverage tests competitive gaps and existing assets. Optimize turns verified gaps into page improvements. Win connects prioritized actions to business outcomes.

For local work, apply the stages to location and service pages using [local SEO evidence](seo-local.md). Cite the inputs behind each recommendation and label unavailable competitive or conversion data. See the [FLOW source and license](../notices/attribution.md).
