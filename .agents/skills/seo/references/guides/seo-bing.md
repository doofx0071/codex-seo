# Bing search evidence

Review supplied Bing Webmaster Tools exports for coverage, queries, impressions, clicks, crawl or inspection findings. Record property scope, date range, filters and sampling. Cross-check public sitemap and directives through host tools when exposed.

Use [search and analytics evidence](../topics/search-analytics.md) for interpretation. Public search results do not establish total coverage or IndexNow delivery. State which data is unavailable. Do not submit URLs or change Bing settings.
