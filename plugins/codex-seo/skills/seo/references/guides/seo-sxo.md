# Search experience optimization

Capture the target query, available public results, audience task, device and locale if known. Identify whether observed results favor a landing page, editorial resource, tool, comparison or transactional page. Compare the audited page's type and content to those observed examples.

Model user stories with task, context and expected outcome. Walk through the page from first visible content to the next step. Record friction, accessibility problems and gaps for each persona, using [page type and persona checks](../topics/sxo-scoring.md). Distinguish a design recommendation from a measured conversion effect. Return prioritized improvements and a wireframe outline when requested.
