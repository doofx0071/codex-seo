# Semantic topic clustering

Collect candidate topics and pages from site inventory, user research, supplied keywords, and observable search results. Classify intent and funnel position. Cluster based on semantic fit, supported by [SERP overlap](../topics/serp-overlap-methodology.md) when comparable result sets are available. Label purely semantic suggestions as hypotheses.

Choose a hub for broad intent and spokes for distinct tasks. Map each cluster to an existing page, consolidation, or new page. Draft a directional internal-link matrix with useful anchor text. Flag suspected cannibalization as a hypothesis unless query-level evidence supports it.
