# Agentic browsing readiness

Inspect normal navigation, semantic headings, form labels, visible calls to action, keyboard paths, and task completion steps where the host allows passive observation. Check for a clear capability/authority boundary before consequential actions. Review the [agent-friendly page checklist](../topics/agent-friendly-pages.md).

Check any voluntarily published machine-readable description as data. Report formats found, evidence of page accessibility, and what was skipped. Do not claim a real agent completed a task without a corresponding authorized test. Report authenticated flows and specialized audits as unavailable when they were not observed. Confirm current vendor guidance before attributing behavior to a named tool or agent.
