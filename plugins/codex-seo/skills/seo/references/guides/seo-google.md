# Google search, analytics and performance data

Review user-provided Search Console, GA4, PageSpeed Insights, CrUX, YouTube or keyword exports as requested. Record source, property or origin, URL, dates, filters, segmentation and metric definitions. Use [search and analytics evidence](../topics/search-analytics.md) and [Core Web Vitals](../topics/cwv-thresholds.md) to prevent mixing scopes.

Distinguish Search Console clicks and impressions from GA4 sessions and conversions. Locate evidence of index status separately from analytics, public previews, and sitemaps. Label browser and field metrics correctly. Without a relevant report or authorized existing host evidence, mark the metric unavailable. Keep indexing and property settings read-only.
