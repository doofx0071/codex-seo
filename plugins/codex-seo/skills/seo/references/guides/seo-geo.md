# AI search and generative engine optimization

Review clear answers, readable structure, original evidence, consistent named entities, media and trustworthy references. Tie suggestions to specific observable pages. Record citation or mention observations with the surface, query, date and accessible result. A content assessment is a readiness judgment. Actual visibility requires observations.

Check crawler access by purpose using [AI crawler access](../topics/ai-crawler-access.md). Check robots.txt and controls separately, then confirm how the specific surface documents its crawler. Treat llms.txt as optional discovery material and describe any status with the [llms.txt evidence guide](../topics/llmstxt-evidence.md). Review [Google's AI feature guidance](https://developers.google.com/search/docs/appearance/ai-features) for Google-specific claims.
