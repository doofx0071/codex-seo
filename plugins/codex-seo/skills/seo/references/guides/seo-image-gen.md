# SEO image briefs

Translate the page's purpose into an image brief. Specify subject, audience, dimensions, crop constraints, placements and accessibility needs. Use the [image brief checklist](../topics/image-brief.md) to plan product accuracy, rights and relevant metadata. Prefer source photos when factual appearance matters.

If the user asks for an image, use a suitable host image capability when available and authorized. Otherwise deliver the brief and label image generation unavailable. Review any supplied or generated image in context and recommend the format, responsive sizes and relevant alt text using [image optimization](seo-images.md).
