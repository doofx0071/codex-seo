# Backlink profile review

Use a supplied export or verifiable individual source and target pages. Record provider, index date, scope, and whether data is sampled. Keep backlink, referring domain and search-result mentions distinct. Profile relevant linking pages, anchors, target destination, link attributes and obvious duplication. Use [backlink quality](../topics/backlink-quality.md).

Do not estimate backlink counts, changes, competitor gaps or risk scores without adequate evidence. A public mention is a lead unless the link is verified. Unknown owner intent, indexing status and provider coverage remain unavailable. Recommend investigation and outreach only when supported. Do not submit a disavow.
