# Full website audit

Identify the business model and sample the homepage plus representative indexable templates. Record each attempted URL, final URL or failure, template, and evidence available. Inspect robots.txt and sitemaps before expanding the sample. An inaccessible URL is unavailable evidence unless the host provides a reliable response showing the failure.

Review [technical SEO](seo-technical.md), [content](seo-content.md), [on-page SEO](seo-page.md), [schema](seo-schema.md), [performance](../topics/cwv-thresholds.md), [AI search readiness](seo-geo.md), and [images](seo-images.md). For sitemap, visual and mobile checks, and relevant specialist areas, use the [role prompts](../roles/index.md). Use the lead to reconcile overlap.

Score only categories with enough evidence and show how each score was derived. Calculate a weighted overall score only when all categories are assessed. Otherwise show coverage, supported category ratings, and the missing checks. Present scores as toolkit prioritization judgments.

Critical findings include confirmed blockers on important pages. High findings materially affect a key template or discovery. Medium findings are specific optimization opportunities. Low findings are backlog improvements. Include the fix, effort, dependency, and acceptance check. Distinguish isolated issues from recurring patterns using observed pages and counts.
