# Image optimization

Inspect image purpose and alternative text. Empty alt is appropriate for decorative images. Flag missing or unhelpful text on informative images, and evaluate linked or button images by their action. Verify accessible names using the host when possible.

Check width and height or a reserved aspect ratio, expected display size, srcset/sizes or picture markup, loading policy, and appropriate format. Check whether the likely hero is discoverable early and avoids lazy loading. Report byte size, actual chosen source, and largest-contentful-paint attribution only with supporting evidence.

Prioritize recurring template issues, especially content-bearing images and high-visibility page elements. Give suggested fixes without modifying deployed files or assets during an audit.
