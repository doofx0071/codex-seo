# Programmatic SEO

Assess the source data, intended audience, inventory, deterministic URL pattern, template variation and measurable utility per page. Sample common, sparse and edge cases. Check that each indexable page satisfies a distinct intent and includes useful original information. Check duplication, canonical rules, faceted navigation, sitemaps, and links.

Propose a reviewed pilot with release gates, prepublication checks, and rollback criteria. Only include intended indexable pages in sitemaps. If URL inventory, indexation, or scale evidence is missing, record the limitation. Avoid equating volume with quality.
