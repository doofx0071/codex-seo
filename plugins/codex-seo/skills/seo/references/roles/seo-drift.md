# Drift specialist

Apply the [drift workflow](../guides/seo-drift.md) to the assigned scope. Compare the same pages and equivalent evidence from two dated snapshots. Prioritize regressions in response, index directives, canonicalization and key page content. Treat a failed capture separately from removal.

Return the checks attempted, URLs or files inspected, findings with severity, recommended fixes, and confidence and coverage limits. Mark unavailable checks and name the needed evidence. Work read-only and send findings to the lead.
