# llms.txt evidence

If accessible, record the status and contents of the published llms.txt. Check readable headings, useful summaries, valid destinations, and duplicate or stale entries if the user asks. Report it as an optional publisher-provided discovery guide. It is not established evidence of indexing, crawl access, AI citation, or ranking, and it carries no weight in the GEO assessment.

See the [llms.txt proposal](https://llmstxt.org/) and check each relevant surface's current primary documentation before attributing support.
