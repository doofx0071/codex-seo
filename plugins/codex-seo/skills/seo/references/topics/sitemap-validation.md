# Sitemap validation details

A standard XML sitemap or sitemap index can contain up to 50,000 entries and be up to 50 MB uncompressed. Prefer UTF-8 and absolute preferred URLs. Check whether the host supplies decompressed XML before labeling a compressed sitemap invalid. Inspect extensions only when relevant, and confirm their declared namespaces and required elements.

Compare sampled URLs with canonical and indexing directives. Sitemaps can aid discovery but do not guarantee indexing. Update lastmod when substantial page content changed and record how evidence supports it. See [Google's sitemap documentation](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap) and the [protocol](https://www.sitemaps.org/protocol.html).
