# Content brief by page type

| Type | Useful outline | Evidence to gather |
|---|---|---|
| Guide | Answer, prerequisites, steps, examples, pitfalls | Expert review, original examples, sources |
| Product or service | Audience fit, offer, specifics, proof, next action | Current specifications, pricing or terms, first-hand evidence |
| Location | Services, coverage, logistics, proof, contact | Hours, address or service area, local examples |
| Comparison | Criteria, alternatives, tradeoffs, best-fit use cases | Verified features, dates, method, commercial relationships |
| Category | Scope, subcategories, selection guidance, links | Current taxonomy, inventory, intended filters |

Tie the primary topic and terminology to the user's needs. Include related internal links only where they support the task, and label proposed URLs.
