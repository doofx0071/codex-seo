# Ecommerce evidence

Match visible product and variant details to markup, especially identity, currency, amount, availability, condition and eligible review content. Record differences by exact URL and variant state. Treat merchant account, feed and marketplace findings as separate data. Use supplied exports only for the scope and date they cover.

If a public Universal Commerce Protocol profile is visible, report fields and declared capabilities as observed. Report actual availability or operation only with supporting authorized evidence. See [Google's product structured data](https://developers.google.com/search/docs/appearance/structured-data/product) and [UCP specifications](https://ucp.dev/).
