# International page parity

For each locale, match the intended page family, translated product or service facts, calls to action, legal requirements, and localized dates, currency, address and telephone labels. Record deliberate local adaptations separately from missing content. Use available language expertise or mark translation quality as unavailable.

Check reciprocal annotations and the canonical of each page before calling pages equivalent for indexing. See [Google's localized version guidance](https://developers.google.com/search/docs/specialty/international/localized-versions).
