# Agent-friendly pages

Inspect discoverability from real links, informative titles, meaningful landmarks, clear names and roles, form labels, and understandable error states. Compare raw and rendered views if both are available. Note when a control is mouse-only, unlabeled, obfuscated, or inaccessible to a host's passive browser.

Document visible actions and prerequisites such as sign-in. A machine-readable capability description is evidence of publication. It does not establish that the declared operation works or is safe to invoke. Review advertised steps and the displayed confirmation process without triggering writes or external actions.
